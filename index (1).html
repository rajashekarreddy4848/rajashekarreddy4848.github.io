A Little About Me

I care about catching what breaks before a user ever sees it.

My career is built on a strong manual testing foundation — writing test cases and running regression, integration, and UAT cycles across QA, staging, and production — before I moved into building test automation end-to-end.

That grounding still shapes how I test today: I built frameworks with Selenium and Protractor, tested mobile apps with Appium, and ran cross-browser validation on BrowserStack and Sauce Labs. Later, I expanded into API testing with Postman and REST Assured, and backend load testing with JMeter.

Now I design Playwright and Cucumber BDD frameworks, and use GitHub Copilot and Claude to move faster — without ever cutting corners on quality.

Quality is a Process

How I work

I start by understanding what the system is supposed to do and where it usually breaks. Then I plan the right coverage — not everything, but the things that matter most. I test across UI, API, database, and integration layers. I automate the repeatable parts so the team gets instant feedback. And I keep improving — analyzing what slipped through, tightening coverage, and making the framework more reliable over time.
