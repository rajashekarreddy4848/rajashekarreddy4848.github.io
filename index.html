A little about me

I care about catching what breaks before a user ever sees it. My career is built on a strong manual testing foundation — writing test cases and running regression, integration, and UAT cycles across QA, staging, and production — before I moved into building test automation end-to-end. That grounding still shapes how I test today: I built frameworks with Selenium and Protractor, tested mobile apps with Appium, and ran cross-browser validation on BrowserStack and Sauce Labs. Later, I expanded into API testing with Postman and REST Assured, and backend load testing with JMeter. Now I design Playwright and Cucumber BDD frameworks, and use GitHub Copilot and Claude to move faster — without ever cutting corners on quality.
