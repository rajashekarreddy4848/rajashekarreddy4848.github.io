A little about me

I started in manual testing — writing test cases and running regression, integration, and UAT cycles across QA, staging, and production builds — before moving into automation. At Scriptbees IT, I built end-to-end automation using Selenium WebDriver (Java) and Protractor (TypeScript/JavaScript), tested mobile apps with Appium and Android Studio, and ran cross-browser validation on BrowserStack and Sauce Labs. On a Tech Mahindra client engagement, I expanded into API testing with Postman and REST Assured, and backend/load testing with JMeter. Today I build with Playwright and Cucumber (BDD), and use GitHub Copilot and Claude to move faster without cutting corners.
